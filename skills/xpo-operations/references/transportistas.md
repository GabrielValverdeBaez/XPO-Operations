# Selección de transportistas

1. Leer histórico verificado por mismo cliente+ruta exacta, exacta con otro cliente, inversa y corredor. Mostrar número de viajes solo si está documentado; no convertir cobertura declarada en viaje realizado.
2. Revisar todo Directorio.xlsx vigente en OneDrive y sus hojas relevantes, usando cabeceras para identificar hojas. Comprobar estilos de celdas: rojo significa NO OFRECER y excluye también sus correos. Si no se puede comprobar un formato relevante, no aprobar el candidato.
3. Por defecto interpretar la búsqueda como segunda ronda: excluir habituales de primera llamada salvo instrucción de incluirlos. Esto no es un veto permanente. Recuperar lista contextual del histórico privado, no inventarla.
4. Ampliar por origen/destino, provincias cercanas, inversa, retornos, corredor, cobertura, servicio/equipo y especialidad; no detenerse en una coincidencia.
5. Ampliar con búsqueda web actual después del histórico y directorio. Verificar web oficial, contactos y encaje; separar claramente procedencia. No inventar disponibilidad ni capacidad ADR a partir de certificación.
6. Encabezar con viajes XPO previos relevantes y después candidatos por ruta declarada/cobertura/ubicación, indicando fuerza de evidencia. Aplicar bloqueos privados antes de todo bloque de correos.

Si no hay acceso a histórico o al libro real, indicar cobertura parcial y continuar solo tareas independientes autorizadas; no presentar como selección exhaustiva o aprobada. Consultar xpo-carrier-selector para contratos de respuesta y criterios especializados vigentes.

Consultas documentales y persistencia del índice privado: [Caché del proyecto](cache.md). Una consulta de caché no acredita disponibilidad ni sustituye la comprobación del Directorio para selección comercial.
