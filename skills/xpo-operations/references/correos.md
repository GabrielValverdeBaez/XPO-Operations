# Correos y memoria

Para extraer de un fichero, leer su contenido actual completo. Extraer direcciones literales, limpiar espacios accidentales, normalizar minúsculas y eliminar duplicados conservando orden. No inventar ni autocorregir dominios. Entregar en bloque copiable separado por `; ` y con `;` final.

Distinguir extracción documental (qué contenía el fichero) de contactos utilizables para una carga. Para estos últimos consultar exclusiones vigentes de empresa/correo y el formato rojo del maestro. No exportar bloqueados. Pasar exclusiones al script mediante archivo privado local; no versionarlo. No interpretar ausencia de lista como ausencia de bloqueos.

No enviar correos sin instrucción expresa de envío y resolución de destinatarios. No añadir a una lista comercial por el mero hecho de extraerlos.

Conservar listas y archivos comerciales en fuente privada, con referencia recuperable en contexto autorizado. Git público solo conserva el procedimiento y datos sintéticos. No afirmar memoria permanente de ChatGPT si no existe herramienta de guardado. Para actualizar listas, releer fuente vigente y preservar identidad del fichero; no usar un chat anterior como maestro.
