# T-016 - Despliegue Cloudflare y aceptacion HTTPS persistente

## Goal
Aplicacion web privada funcional en Cloudflare sin dependencia del Mac mini, conservando la version local.

## Why
Cumplir la ampliacion autorizada de O-005 sin confundir recursos creados con una aplicacion desplegada.

## Inputs
Adaptador validado T-015; Worker, D1 UE y conexion GitHub dedicados ya creados. IDs exactos en docs/CLOUDFLARE_DEPLOYMENT.md.

## Outputs
T-016-output sera evidencia de version desplegada, URL real, acceso privado y persistencia remota. **Todavia no producido.**

## Acceptance Criteria
Construccion/despliegue real exitoso, bind DB exclusivamente a xpo-load-studio-db, HTTPS verificado, autenticacion y limitador eficaces, datos sinteticos persistentes despues de nuevo despliegue, deduplicacion y logout, sin secretos/datos operativos expuestos. No contratar planes de pago.

## Verification
Worker existe con deployed_on null, workers.dev y previews deshabilitados. D1 remota responde SELECT 1; no acredita la app. CI workerd+D1 local PASS no equivale a aceptacion remota. Falta credencial de publicacion; el endpoint de tokens responde 403 no compatible con OAuth. No reutilizar credenciales de otro proyecto.

## Evidence
Estado, pruebas y siguiente accion precisa: docs/CLOUDFLARE_DEPLOYMENT.md.

## Guardrails
No marcar DONE por tener un nombre de Worker o una URL asignada. No compartir tokens en chat. Mantener acceso cerrado hasta configurar el Secret. No fusionar PR automaticamente ni modificar otras aplicaciones.

## Failure / Recovery
Si la publicacion falla, conservar base y Worker; inspeccionar el build concreto. Corregir fallos reversibles y repetir pruebas. Si falla privacidad, deshabilitar rutas publicas de este Worker y registrar la causa. No borrar recursos o datos como atajo.

## Handoff
Una sesion de configuracion en el panel de Cloudflare: autorizar credencial propia de XPO y Secret de acceso. Despues inspeccionar trigger/build, desplegar y ejecutar aceptacion remota. No repetir reconexion MCP: la lectura y escritura de recursos ya funcionan.
